Built on OpenBSD's legendary security, with a CLI network engineers already know.

Packet Filter (PF)

OpenBSD's renowned stateful firewall with NAT, traffic shaping, and real-time state monitoring.

Dynamic Routing

Full BGP4, OSPF, and RIP support via OpenBGPD and OpenOSPFD. Enterprise routing made simple.

VPN

IKEv2, IPSec, and WireGuard support. Secure site-to-site and remote access VPN built-in.

High Availability

CARP failover with pfsync state synchronization. Zero-downtime failover in milliseconds.

Central Management
