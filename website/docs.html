NSWall Documentation

Learn how to deploy and configure NSWall for your network.

What is NSWall?

NSWall is an OpenBSD-based network appliance framework that provides a familiar Junos/IOS-style CLI for managing firewalls, routers, and network services.

Installation

Option 1: Virtual Appliance (Recommended)

Download a pre-built VM image for your platform:

# Download OVA for VMware
curl -LO https://downloads.nswall.io/latest/nswall-latest.ova

# Import into VMware
ovftool nswall-latest.ova

Option 2: Build from Source

# Clone repository
git clone https://github.com/northshorenetworks/NSWall.git
cd NSWall

# Build (requires OpenBSD)
make KCONF=GENERIC-RD

# The kernel image will be at bsd.gz

Quick Start

After booting NSWall, connect via console or SSH and run:

nswall> enable
nswall# configure terminal

# Set hostname
nswall(config)# hostname my-firewall

# Configure WAN interface
nswall(config)# interface em0
nswall(config-if)# ip address dhcp
nswall(config-if)# no shutdown
nswall(config-if)# exit

# Configure LAN interface
nswall(config)# interface em1
nswall(config-if)# ip address 192.168.1.1/24
nswall(config-if)# no shutdown
nswall(config-if)# exit

# Enable firewall
nswall(config)# pf enable

# Save configuration
nswall(config)# exit
nswall# write memory

Firewall (PF)

NSWall uses OpenBSD's Packet Filter (PF) for firewalling.

Basic Rules

# Allow SSH
nswall(config)# pf add filter pass in on em0 proto tcp to port 22

# Allow HTTP/HTTPS
nswall(config)# pf add filter pass in on em0 proto tcp to port { 80 443 }

# NAT outbound traffic
nswall(config)# pf add nat on em0 from 192.168.1.0/24 to any -> (em0)

# Apply rules
nswall(config)# pf reload

Show Commands

nswall# pf show rules     # Show filter rules
nswall# pf show nat       # Show NAT rules
nswall# pf show states    # Show state table
nswall# pf show info      # Show PF statistics

VPN

NSWall supports IKEv2, IPSec, and OpenVPN.

IKEv2 Site-to-Site

nswall(config)# iked enable
nswall(config)# iked edit

# In editor, add:
ikev2 "site-to-site" passive esp \
    from 10.1.0.0/24 to 10.2.0.0/24 \
    peer 203.0.113.1 \
    psk "your-shared-secret"

Routing

Static Routes

nswall(config)# route add 10.0.0.0/8 192.168.1.254
nswall# show route

BGP

nswall(config)# bgp enable
nswall(config)# bgp edit

# Configure BGP peering
AS 65001
neighbor 192.0.2.1 {
    remote-as 65002
    announce all
}

nswall# show bgp summary

High Availability

Use CARP and pfsync for failover.

# Primary firewall
nswall(config)# interface carp0
nswall(config-if)# carp vhid 1 pass secret123
nswall(config-if)# carp advskew 0
nswall(config-if)# ip address 192.168.1.1/24

# State sync
nswall(config)# interface pfsync0
nswall(config-if)# syncdev em2
nswall(config-if)# syncpeer 10.0.0.2

Common Commands
