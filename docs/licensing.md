## Frequently Asked Questions

### Is the source code really open?

**Yes.** All source code is publicly available on GitHub. You can read it, learn from it, modify it, and contribute to it. The licensing only affects *how* you use it.

### What counts as "commercial use"?

Commercial use means using NSWall in a for-profit business context:
- Protecting your company's network
- Using it in client deployments
- Including it in a product you sell
- Running it in a revenue-generating environment

### Can I try it before buying?

**Absolutely.** Use it freely for evaluation. The Community License covers testing, labs, and proof-of-concept deployments. Only purchase when you move to production.

### What if I'm a consultant?

If you deploy NSWall for clients, each client deployment needs appropriate licensing. We offer consultant/MSP programs with volume discounts.

### Can I modify the code?

**Yes.** You can modify NSWall for your needs. If you're using it commercially, you still need a commercial license for the modified version.

### Do I have to share my changes?

For Community License: We encourage (but don't require) contributing improvements back.

For Commercial License: No requirement to share modifications.

### What about cloud/SaaS use?

Using NSWall to provide network services to others (managed firewall, cloud security service) requires a Commercial License and may require an additional SaaS agreement. Contact us.

### I'm a startup with no revenue yet

Contact us! We have startup-friendly pricing for early-stage companies. Typically free until you reach certain revenue thresholds.
